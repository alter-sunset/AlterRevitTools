## Экспорт моделей
Модуль позволяет экспортировать пакет моделей:
  - В файлы формата .nwc (кэш Navisworks) с заранее установленными настройками
  - В файлы формата .ifc с заранее установленными настройками
  - Для передачи их вне организации. (Реализует схожий функционал с *eTransmit*, но работает быстрее, т.к. не выполняет поиск вложенных связей. Также модуль удобно использовать для быстрой подготовки моделей, полученных от подрядчика.)

  **Важные моменты:**
  - Конфигурацию экспорта можно сохранить в файл формата .json для дальнейшего повторного экспорта.
  - Файлы будут автоматически обновлены до используемой версии Revit.
  - Все ссылки могут быть выгружены или удалены из модели.
  - Модели могут быть очищены от пустых рабочих наборов. *(Начиная с версии **2022**)*
  - Модели могут быть очищены от неразмещённых помещений.
  - Модели могут быть очищены от всех неиспользуемых элементов.
  - Из модели можно удалить листы и виды.

## Миграция моделей
Модуль предназначен для миграции проекта в новое место с сохранением структуры связей. Например при переходе от стадии П к стадии Р. <br>
В модуль загружается файл .json, содержащий *Dictionary<string, string>*, где ключ - полный путь исходного файла, а значение - полный путь итогового файла.
